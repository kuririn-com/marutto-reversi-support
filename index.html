途中の対局を再開するには

ホームの「続きから」で再開できます。対局、戦績、設定は端末内に保存されます。機種間の同期・移行機能はありません。

広告なし購入について

無料版にはバナーと、正常に終了した3対局ごとの区切りに全画面広告があります。広告なしは一度きりの買い切りです。日本の設定予定価格は150円です。購入前にApp Storeの画面に表示される価格をご確認ください。購入済みの場合、設定の「購入を復元」を同じApple Accountでお試しください。

通信がない場合

対局はオフラインでも遊べます。広告、購入、購入の復元や再確認には通信が必要となる場合があります。

返金について

購入と返金はAppleが処理します。Appleの購入サポートをご確認ください。

端末内に保存する情報

対局の盤面と履歴、戦績、設定、広告表示の間隔、検証済みの広告なし利用権を端末内に保存します。アカウント登録は不要です。開発者独自の対局サーバー・利用解析サーバーはありません。

広告と同意

無料版ではGoogle AdMobを利用します。広告を要求する前にGoogle User Messaging Platformで同意情報を更新し、必要に応じて同意画面を表示します。地域の要件に応じ、設定から広告のプライバシー選択を変更できます。

広告SDKは、IPアドレスから推定されるおおよその地域、端末・アプリの識別情報、広告の表示・操作情報、クラッシュやパフォーマンス等の診断情報を処理する場合があります。パーソナライズ広告を要求しない場合も、広告配信や不正防止等のための情報処理が発生し得ます。

アプリはパーソナライズ広告を要求せず、IDFA取得を目的とするATTの許可要求も行いません。Google Mobile AdsのSame App Keyは無効です。広告なしの購入権限を確認した利用者には広告を要求・表示しません。Googleのプライバシーポリシーと広告SDKのデータ開示資料もご確認ください。

購入と復元

広告なしはAppleのApp Storeを通じた非消耗型の購入です。決済はAppleが処理し、アプリはカード番号を取得しません。StoreKitで商品と購入権限を確認し、利用権を端末に保存します。返金・取り消し等による利用権の消失を確認した場合は広告を再開します。Appleのプライバシーポリシーをご確認ください。

ブラウザー体験版

体験版は広告のサンプルを表示します。実際の広告配信やAppleへの購入要求は行いません。無料体験の状態はブラウザー内に保存します。

データの削除

アプリを削除すると端末内の保存データは削除されます。OSの設定によりバックアップされる場合があります。バックアップはOSやサービスの設定で管理してください。アプリの削除でAppleの購入履歴自体は削除されません。

このサポートサイト

GitHub Pagesで配信します。サイト独自のアクセス解析や広告は使用しません。配信に伴う情報の取り扱いはGitHubのプライバシーポリシーをご確認ください。お問い合わせメールの内容は、回答と不具合の調査に必要な範囲で使用します。
